# RGP Theme 4 Project---Lucas-Carter-23636298
 
Controls:
WASD to move
SPACE to jump
RMB to Pick up Level Segments to move
LMB to Place Level Segments 
R to reload the Level
ESC to return to Main Menu

Reunite the Old-Man with his loved one by piecing the world together to create a path.
Make your way through 5 puzzles by moving segments of the level around to create opportunities to progress.
Have Fun!
